Secret Recipe

เคล็ดลับการเขียน Prompt ที่ดี ✍️

สูตรสำเร็จ 3 องค์ประกอบหลัก สั่ง AI ได้ตรงใจ!

📍

1. ธีมเกมคืออะไร?

ระบุแนวเกม ชัดเจน เช่น ฟาร์ม, อวกาศ, ทำอาหาร, ตะลุยปราสาท

🎮

2. เล่นยังไง?

อธิบายกติกา ปุ่มที่ต้องกด วิธีชนะ วิธีแพ้ และระบบคะแนน

🎨

3. หน้าตาแบบไหน?

กำหนดโทนสี (เช่น สีพาสเทลสดใส) สไตล์ปุ่ม และกริดหน้าจอ

Prompt Comparison

❌ Prompt แย่ vs ✅ Prompt เยี่ยม

❌

Prompt สั้นเกินไป

"สร้างเกมทำฟาร์มให้หน่อย"

⚠️ ผลลัพธ์: AI จะเดาเอาเองทั้งหมด เกมอาจจะไม่ตรงกับที่เราคิดไว้

✅

Prompt มีรายละเอียดชัดเจน

"สร้างเกมทำฟาร์มแบบ HTML5 มีกริด 4x4 ปลูกแครอทได้ มีระบบพลังงาน โทนสีพาสเทล"

✨ ผลลัพธ์: AI ทำได้เป๊ะ ตรงตามโจทย์ ได้เกมสวยงามพร้อมเล่น!
